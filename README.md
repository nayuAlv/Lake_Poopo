# Lake Poopo Climate Analysis

Analysis of essential climate variables of Lake Poopo (Bolivia).

I combine lake-product data from three sources: ESA CCI Lakes, ERA5-Land reanalysis
(Copernicus CDS), and JRC Global Surface Water (Google Earth Engine).

## Data sources

[ESA CCI Lakes v2.1](https://climate.esa.int/en/projects/lakes/) (1992–2022)

[ERA5-Land (CDS)](https://cds.climate.copernicus.eu) (1950–present)

[JRC Global Surface Water (GEE)](https://developers.google.com/earth-engine/datasets/catalog/JRC_GSW1_4_MonthlyHistory)(1984–present)
